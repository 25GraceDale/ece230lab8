## Summary
We implemented a multiplexer and a demultiplexer in order to choose a specific set of bits from an input of interest, and then send that set of bits to a recipient of our choice. We also made it so that the particular set of bits that are sent can be chosen on hardware.

## Lab Questions

### In plain English describe the function and use of a multiplexer.
The multiplexer always us to choose what inputs are important out of multiple possible inputs, and then make that into one output.

### In plain English describe the function and use of a demultiplexer.
The demultiplexer takes a single input, and lets us chose which output out of many to send the input to.

### What other uses might these circuits have? (Think Shannon’s)
Choosing inputs and observing outputs for one variable can allow us to write Boolean logic equations for hardware circuits where other inputs are unknown. The circuits can also be used for things like memory, where someone chooses what to save to memory, and then certain inputs decide what information from memory should be retreived and shown to the user.
